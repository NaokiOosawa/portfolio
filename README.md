# N.O. ポートフォリオ

データベース・業務システムエンジニア（フリーランス）のポートフォリオサイトです。

- 公開ページ：（GitHub Pagesで公開したあと、ここにURLを記載してください）
- 内容：強み、実績、経歴（15案件）、スキルと経験年数、稼働条件

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | ページ本体。HTML・CSS・JavaScriptが1ファイルにまとまっています。外部ライブラリは使っていません（フォントのみGoogle Fontsを読み込みます）。 |
| `.nojekyll` | GitHub Pagesにそのまま公開するための空ファイルです。 |

## 更新のしかた

- 経歴の追加・修正：`index.html` の `const P = [` から始まる一覧を編集します。年表と経歴一覧の両方に自動で反映されます。
- スキルの年数：`const SKILLS = [` の一覧を編集します。
- 連絡先の掲載：`const CONTACT = { email: "", github: "" };` に入力すると、ページに表示されます。

## 表示

- スマートフォン・PCの両方に対応しています。
- ダークモードに対応しています。
- 印刷（PDF保存）に対応しています。経歴はすべて開いた状態で出力されます。
